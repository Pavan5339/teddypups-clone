# TeddyPups clone

Clone of https://puppy.instabizweb.com/ (TeddyPups U.A.E., teacup puppies in Dubai) for the Blutec AI technical assignment.

- Plain HTML, CSS and JavaScript, no build step. Hash router: `#/`, `#/puppies`, `#/puppies/<slug>`, `#/happy-families`, `#/how-it-works`, `#/faq`, `#/contact`, `#/gone-home`.
- Responsive (mobile menu, fluid grids). Photo gallery, breed and origin filters, FAQ search and accordion, enquiry form with validation.
- Puppy photos are linked from the original site. Contact form is front-end only (saves to localStorage).
- Deployed with GitHub Pages through `.github/workflows/pages.yml`.
- Built with AI assistance (see Loom walkthrough).
